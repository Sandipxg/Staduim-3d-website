# Meridian Arena Tickets — Docs

3D stadium seat booking demo. Fans pick a stand, a block and a seat on a realistic, code-generated stadium, fly to the view from that seat, and book it. React + three.js frontend, Node (Hono) API with a JSON-file inventory. Status: working prototype.
